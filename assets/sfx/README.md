# SFX Assets

Drop your sound-effect files here using these **exact filenames** so
`modules/highlight_finder.py` cue names resolve correctly:

| Cue name            | Expected filename           |
|----------------------|------------------------------|
| swoosh                | swoosh.mp3                   |
| pop                    | pop.mp3                      |
| vine_boom             | vine_boom.mp3                |
| ding                   | ding.mp3                     |
| whoosh_transition     | whoosh_transition.mp3        |
| impact                 | impact.mp3                   |
| notification           | notification.mp3             |

Recommended sources for royalty-free SFX:
- Pixabay Sound Effects (pixabay.com/sound-effects)
- Mixkit (mixkit.co/free-sound-effects)
- Freesound.org (check individual license per clip)

Keep each file short (under 1.5s) and normalized to a consistent loudness so
none of them overpower the speaker's voice.
